# Shadow Market Desk

Autonomous opportunity-intelligence and revenue orchestration system.

## Mission
Detect lawful public market signals before they become obvious demand; verify them; infer likely buyer needs; estimate fulfillment cost, timing and margin; create structured opportunities; and route the best ones into compliant, human-sounding commercial workflows.

## Core loop
`SIGNAL -> VERIFY -> INFER NEED -> PRICE -> SCORE -> OFFER -> OUTREACH -> FOLLOW-UP -> LEARN`

## Initial LA verticals
1. Commercial permits and tenant improvements -> contractor/service demand
2. New business openings / relocations -> signage, electrical, low-voltage, cleaning, web/GBP
3. Public procurement and pre-RFP signals
4. Surplus/liquidation assets with buyer-first logic

## Revenue objective
Optimize expected gross profit per agent-hour, not activity volume.

## Autonomy guardrails
The system may research public sources, normalize records, rank opportunities, generate non-binding offers, run compliant outreach workflows, learn from outcomes, and reallocate agent attention.

It must not autonomously borrow money, make material speculative purchases, sign binding contracts, impersonate licensed professionals, evade legal/platform rules, misuse sensitive data, or create regulated brokerage/referral arrangements unless explicitly permitted by policy.

## Workstreams
- signal ingestion
- verification and enrichment
- opportunity graph
- pricing and margin estimation
- scoring engine
- revenue allocator
- outreach/CRM state machine
- API/dashboard
- compliance and safety guardrails
- tests, observability and deployment
